# AnimRetargetAndroid — Android APK (1.1.1-test)

Репозиторий для сборки Android-приложения переноса анимаций. Версия 1.1 китайского разработчика добавила импорт и экспорт GLB; тестовая версия 1.1.1 содержит исправления загрузки исходных вращений костей GLB, импорта FBX, настроек ретаргетинга и ошибок Android-интерфейса.

## Как получить APK

1. Скачайте **новый** архив `AnimRetargetAndroid_GitHub_Actions.zip` из чата ChatGPT (25.10.2026, 1.1.1-test).
2. В этом репозитории выберите **Add file → Upload files**; загрузите **один ZIP-файл без распаковки** в корень репозитория, с точным именем `AnimRetargetAndroid_GitHub_Actions.zip`.
3. Нажмите **Commit changes**. Workflow запускается автоматически. Если нет — вкладка **Actions → Build Anim Retarget APK → Run workflow**.
4. После успешной сборки скачайте артефакт **AnimRetargetAndroid-debug-APK** из запуска Actions. Распакуйте его и установите `app-debug.apk` на Android.

**Не путайте архив исходников с готовым APK.** Пока GitHub Actions не выполнит сборку успешно, APK ещё нет.

## Smoke-тест

Код Kotlin компилируется локально. Тест: демон (GLB, 60 костей, 4 анимации) + Mixamo Zombie Attack (GLB, 41 кость, одна анимация). Распознано 34 пары костей; получен GLB с 5 клипами, прежними meshes/skins/materials/textures и сохранённым исходным бинарным блоком. Визуально качество деформаций ещё не подтверждено.

## Ограничения

- Превью пока рисует **линии скелета**, а не скинованный 3D-меш.
- Каждый выбранный клип сохраняется **в отдельный GLB** на основе исходного персонажа. Единого файла со всеми импортированными клипами приложение пока не создаёт.
- В одном ZIP обрабатывается до 200 файлов. Не стоит загружать сразу огромные пакеты на планшете с 4 ГБ ОЗУ.
- Полный Android APK не проверен до успешного запуска Actions.

Исходники и Gradle Wrapper находятся в приложенном ZIP. Подробное описание изменений — `FIXES_1.1.1_TEST.txt` внутри архива.
